# Velaris

Velaris is an AI-native Customer Success platform for mid-market and enterprise B2B SaaS teams — customer data, health scoring, churn/expansion signals, and lifecycle automation with AI agents and a Copilot assistant. The Velaris Public API (https://developers.velaris.io/) exposes organizations, accounts, contacts, opportunities, risks, custom objects, activities, notes, tickets, tasks, users, surveys, and lifecycle stages at https://api.euw1.velaris.io.

Backed by: battery-ventures

This repository profiles the company's API surface for the API Evangelist network: OpenAPI (converted from the provider-published Postman collection), authentication, conventions, lifecycle, error, data-model, security, conformance, MCP-candidate, llms.txt, and agent-skill artifacts, indexed in `apis.yml`.
